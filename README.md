# Shop Plugin – Advanced Economy Shop System

A modern, lightweight, and highly optimized **Minecraft Shop Plugin** designed for SMP servers. Built with **Folia & Paper compatibility**, advanced **pricing customization**, and seamless **Essentials economy support**.

## ✨ Features

* ✅ **Folia Compatible** – Optimized for modern multi-threaded server performance.
* ✅ **Paper Supported** – Fully compatible with modern Paper servers.
* ✅ **Minecraft 1.21.11 Support** – Built and optimized for the latest versions.
* ✅ **EssentialsX Economy Integration** – Smooth and reliable economy support.
* ✅ **Custom Pricing System** – Easily configure and customize item prices.
* ✅ **SMP Friendly** – Perfect for survival multiplayer servers.
* ✅ **High Performance Optimization** – Minimal server impact and efficient processing.
* ✅ **Lightweight & Fast** – Designed to run smoothly without unnecessary lag.
* ✅ **Easy Configuration** – Simple setup with flexible customization.
* ✅ **Stable Economy Handling** – Secure and reliable shop transactions.
* ✅ **Modern & Clean System** – Built for performance, usability, and stability.
* ✅ **Future-Proof Design** – Ready for modern server software and updates.

## 🔧 Compatibility

**Supported Platforms:**

* Paper
* Folia
* Purpur *(compatible in most cases)*

**Minecraft Version:**

* **1.21.11**

**Dependencies:**

* EssentialsX (Economy)

## 💰 Advanced Pricing

The plugin includes a **fully customizable pricing system**, allowing server owners to:

* Set custom item prices
* Balance the SMP economy
* Create a fair trading experience
* Adjust prices based on server progression

## 🚀 Why This Plugin?

This plugin is designed for server owners who want a **fast, stable, and optimized shop system** for their SMP server. With **Folia support, modern optimization, and customizable pricing**, it provides a smooth shopping experience without affecting server performance.

## ⚡ Performance Focused

Carefully optimized to:

* Reduce unnecessary server load
* Work efficiently with Folia threading
* Handle economy transactions smoothly
* Keep gameplay stable on active SMP servers
